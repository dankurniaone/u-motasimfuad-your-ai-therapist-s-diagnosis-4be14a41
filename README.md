`main.py` writes the winning diagnosis to `/output/entry.txt` (UTF-8, 1-200 chars, one line).

## Run

```
python3 main.py            # writes /output/entry.txt
python3 main.py --check    # validates the gate: length, one line, UTF-8
python3 main.py --self-test
python3 main.py --tournament
```
